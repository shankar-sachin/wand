# Changelog

## 1.0.0

First release — see [documentation/RELEASE_v1.0.0.md](documentation/RELEASE_v1.0.0.md).

- Samsung Tizen remote with the physical Smart Remote's layout, in Liquid Glass
- Multiple saved TVs with an instant quick switcher backed by a warm connection pool
- Subnet discovery, Keychain-backed token pairing, and Wake-on-LAN power on
- App keys with real logos, plus install probing over the TV's REST API
- Swipe pad, TV keyboard entry, number pad, and latency diagnostics
- Light and dark, both designed
